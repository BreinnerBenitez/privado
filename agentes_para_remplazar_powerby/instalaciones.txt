== configuraciones adiconales==

ollama list = lista los modelos
ollama serve= inicia el servicio en un segundo plano
ollama pull modelo = descarga el modelo de ia con su contexto
ollama rm modelo= elimina por completo un modelo
ollama show modelo= despliega informacion detallada sobre la arquictectura
ollama ps = muestra los modelos que se estan ejecutando
ollama stop modelo = descarga un modelo de la memoria ram
